# settings-hub — acceptance criteria

> [overview.md](overview.md) を参照。

## Criteria

- [ ] `src/App/View/Settings.purs` が設定ハブレイアウトに書き換えられている。
- [ ] 設定ハブに「アカウント設定」「セッション情報」「ブロック/ミュート（準備中）」「表示設定」セクションが存在する。
- [ ] アカウント設定セクションに現在の `Model.accounts` の一覧または「アカウント一覧へ」リンクが表示される。
- [ ] アカウント設定セクションの各アカウントカードから `/accounts/{id}` へ遷移できる。
- [ ] アカウント設定セクションの各アカウントカードから危険領域（アカウント削除）への導線リンクが表示される。
- [ ] セッション情報セクションに `Model.session.username` が表示される（未ログイン時は「ログインしていません」）。
- [ ] セッション情報セクションのログアウトボタンをクリックすると `Logout` メッセージが発行される。
- [ ] ブロック/ミュートセクションに「今後の機能です」placeholder テキストが表示される。
- [ ] 表示設定セクションに既存のテーマ/形状選択 UI が配置されている。
- [ ] `spago build` が成功する。
- [ ] 各リンクは `App.View.Link` または `Navigate` メッセージを使用している。
