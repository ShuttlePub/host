# 2026-11-22 Local TL・Global TL の流れ先 (D69)

2026-11-22 に operator と設計席の間で、ShuttlePub の体験面を話す中で確定した決定。
[2026-11-21-emumet-p1-open-items.md](2026-11-21-emumet-p1-open-items.md) の続きで、番号を引き継ぐ。

きっかけは、operator が [2026-11-20-problem-domain-and-producers.md](2026-11-20-problem-domain-and-producers.md)
をもとに書いた「認識の整理」と、記録との照合。D45 の「cc 付き、つまり返信などは、文脈を保つために
Local TL に流してよい」が、次の 2 点で問題になった。

- 公開返信を Global TL から除く決定なのか、Local TL への追加表示なのかが読み取れない
  (「流してよい」は許可だが、「ただの Note → Global TL」と対に書いているので振り分けにも読める)。
- cc は返信の判定に使えない。Mastodon の公開投稿はふつう `to: Public`、`cc: フォロワーの URL`
  なので、普通の公開投稿のほとんどが「cc 付き」になる。

## 決定

| # | 決定 | 内容 | 状態 |
|---|------|------|------|
| D69 | Local TL・Global TL の流れ先 (D45 の改訂) | Local TL に並ぶのは、この ShuttlePub から投稿されたもの (返信を含む) だけとする。外部のサーバーから届いた返信は、このサーバーの会話に関係していても Local TL には足さない (D45 の「cc 付きは Local TL に流してよい」を取り消す)。Global TL は、このサーバーが受け取った公開投稿をまとめて見せる。外部から届いた返信も、公開なら Global TL に入る。外部からの返信が見える場所は、Global TL、宛先の Profile のホーム TL と通知 (Producer ③、D26)、投稿を開いたときのスレッド表示。ここの利用者が外部の投稿に返信したとき、親の投稿を取得してツリーで見せる案とは両立する (Local TL に並ぶのはここの利用者の返信で、外部の親は文脈として一緒に表示するだけ) | 確定 |

## 今回の決定に含めないもの (未決)

照合の中で出たが、確定していないもの。

- **Global TL に入れる公開範囲の判定**。案は「`to` に Public を含むもの (公開) だけを入れ、
  Public が `cc` にだけあるもの (未収載) は入れない」(Mastodon と同じ)。D45 の未決「Global TL に
  流す範囲」の続き。
- **外部の親投稿の取得**。ここの利用者が外部の投稿に返信したとき、親を取得して表示する案。
  リモートの object を取得する口が要る (D50 の `port` にあるのはリモート actor の取得まで)。
- **ShuttlePub がリレーに参加する側になるか**。記録にあるのは、外から連合を申し込まれる側だけ
  (D43 ②・D44)。ShuttlePub から外部のリレーへ Follow しに行くのは新しい話。D44 の「他サービスへの
  転送 (後で)」は、受けた投稿を購読者へ回す配信側の話で、これとは別。配信側のリレー機能が要るか、
  要るなら何をどこへ転送するかも未決。
- **コミュニティごとの設定 (operator の案)**。管理者が「参加者のフォロー先の投稿を Emumet から
  配送するよう要求するか」を選び、参加者が許可するかを選ぶ。コミュニティ Chat のような用途では
  要求せず、Local TL だけで構成する。照合で出た論点:
  - Global TL の材料は外部リレー (②)、ホーム TL の材料は Emumet からの転送 (③) で、出どころが違う。
    Chat 用途にするには「リレーを無効にする」と「転送を要求しない」の 2 つの設定が要る。
    「リレーを有効にするか」の管理者設定も新しい案。
  - 転送を要求しないサーバーはホーム (信頼モード ③) になれない (D26)。ホームになれないサーバーを
    認めるか。
  - 参加先 (信頼モード ②) にフォロー先の投稿を流すのは、D55 で P2 に持ち越した問い
    「② の link へ転送するのは、その link の名前空間の投稿への返信・反応・リポストだけでよいか
    (推奨: はい)」とぶつかる。「はい」にするとこの案は成り立たない。
  - フォロー先の投稿にはフォロワー限定・ダイレクトもある。共有の TL (Local / Global) に出せるのは
    公開・未収載だけで、ほかは個人の TL に限る。
  - 参加者の許可は link の信頼モードにあたり、D31・D46 では Emumet の確認画面で行う。ShuttlePub の
    画面から始めるなら、Emumet の同意画面へ移る形になる。

## 過去の決定との関係

- **D45** (タイムラインの呼び方と流れ先): 呼び方 (Local TL・Global TL) と、① の投稿は Local TL、
  ③ はホーム TL・通知という部分は維持。「cc 付き、つまり返信などは Local TL に流してよい」を
  D69 で置き換える。
- **D26** (ホーム): 維持。外部からの返信のうち Profile 宛てのものは、ホーム TL と通知で見える。
- **D47** (KJ法のまとまり): 流れ先を決める判断は「タイムライン」のまとまりに置いたまま。
  D69 の判定に Emumet への問い合わせは要らない (投稿がこの ShuttlePub から来たかどうかで決まる)。
